# Beauty Planner: Studio support

Beauty Planner is a customizable beauty-event workspace. Every studio enters its own business details in the app.

## Get help

Open an issue describing your device, app version, what you expected, and what happened. Support requests here are public: do not include client names, contact information, medical details, documents, access tokens, or private screenshots.

For booking, appointment, payment, or studio-record questions, contact the studio you chose. This repository handles app software support.

No application source code or customer data is stored in this repository.
